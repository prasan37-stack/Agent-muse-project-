## Field guide

- **Defect ID**: Unique ID, format `DEF-001`, `DEF-002`, …
- **Test Case ID**: The failing test case, e.g. `TC_FR001_13`.
- **Severity**: Critical / Major / Minor / Cosmetic — how badly it breaks the functionality.
- **Priority**: Critical / High / Medium / Low — how urgently it must be fixed.
- **Status**: Open → In Progress → Fixed → Retest → Closed (or Reopened).
- **Retest Result**: Pass / Fail after the fix is verified.
