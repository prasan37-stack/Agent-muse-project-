# Manual Test Cases

This folder holds manual (human-executed) test documentation.

## Files

- `Test_Case_Template.md` — blank template. Copy it for every new test case.
  Fields: Test Case ID, Test Description, Preconditions, Test Steps, Test Data,
  Expected Results, Actual Results, Status (Pass/Fail), Notes.
- `FR001_Mortgage_Calculator_Manual_Test_Cases.md` — the 25 detailed manual test
  cases for the Wells Fargo mortgage calculator (FR001), converted from the
  original spreadsheet. Fill in **Actual Results** and **Status** as you execute.
